About CoachView

CoachView is a workout video platform built for coaches and viewers. Coaches can upload training videos and viewers can browse the library.

  • Registration and authentication
  • Coach-only video upload
  • Video listing and streaming
  • Browser UI built as a real multi-page app

Note: this prototype uses in-memory user storage and local upload storage. For production, add a database and cloud media storage.
